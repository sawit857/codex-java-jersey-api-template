# Workflow gates

## Analysis
- [ ] scope and contract clear
- [ ] exact impacted files and owners
- [ ] tests planned
- [ ] risks/assumptions/questions explicit
- [ ] approved plan persisted

## Implementation
- [ ] approved plan followed
- [ ] authorized files only
- [ ] Java 8/`javax` compatible
- [ ] compile evidence passes

## Testing
- [ ] service/repository/Jersey coverage
- [ ] actual non-zero discovery
- [ ] zero failures/errors
- [ ] valid failures preserved and correctly routed

## Review
- [ ] independent read-only review
- [ ] findings validated by parent
- [ ] no unresolved CRITICAL/HIGH
- [ ] accepted report current

## Documentation
- [ ] endpoints/models/errors/examples complete
- [ ] no invented behavior
- [ ] contract consistency verified

## Final
- [ ] `mvn clean verify` fresh and passing
- [ ] tests executed
- [ ] artifacts current
- [ ] working tree contains no unexpected output/secrets/debug files
